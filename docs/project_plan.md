## Projektin sisältö

### Kuvaus
SoitinStock on soitinvuokraamon inventaario järjestelmä/sovellus, jossa työntekijät pystyy seuramaan soittimien vuokraustilaa ja soittimien saldoa.
Järjestelmä on suunniteltu hallinnoimaan soitinvuokraamon kivijalan varastoa, ja palvelemaan parhaiten vuokraavia asiakkaita.

### Projektiryhmä
| Nimi              | Vastuurooli          |
| ------------------| -------------------- |
| Minttu Räisänen   | Git-päällikkö, Backend ja Tietokanta Dev, Scrum Master |
| Jun Fengari       | Dokumentti-päällikkö, Julkaisuvastaava, AWS Dev |
| Thomas Vainikainen| Git-päällikkö, Product Owner, Frontend Dev |
| Oskari Puranen    | UI/UX |

### Tavoite
Tavoiteltu lopputulos on alustavasti MVP, johon kuulu toimiva kirjautuminen, toimiva inventaariosovellus jossa on integraatio front-, backend sekä AWS välisesti.
Sovelluksen toimivuustavoite on että työntekijä (käyttäjä) pystyy vuokraamaan asiakkaalle soittimen.

## Raportointi, kommunikointi ja dokumentointi

### Raportointi
Dokumenttipäällikkö luo raportin koostaen viikon saavutukset sekä kokouksien palautteet. 

### Tuntikirjaukset
Tuntikirjaukset tehdään Teamsissä ryhmän sisäisesti, jokaisella opiskelijalla on oma seurantataulukko. 

### Palaverikäytänteet
Projektin viikottainen sprint planning pidetään maanantai aamuna, ja daily scrumit pidetään päivittäin aamusin (kesto 15min). Retrospective pidetään perjantaina iltapäivällä. 
Palaveripöytäkirja sijaitsee yhteisessä docs tiedostossa. 

### Kommunikointitavat
Tiimi kommunikoi kasvotusten, sekä Teamsin välityksellä. 

### Dokumentointi
Tuotetaan opintojakson vaadittavat dokumentit: tärkeimpänä README, projektisuunnitelma, sekä KeHu. Kooditiedostoihin tehdään asianmukaiset kommentit. Dokumentointikieli on pääsääntöisesti englanti. 

### Dokumenttien hallinta
Dokumentit säilytetään sekä githubissa että jaettuna OneDriven kautta kaikille tiimiläisille. 

## Riskien hallinta

| Riskit                                                       | Todennäköisyys | Impakti | Minimointi                             |
| ------------------------------------------------------------ | -------------- | ------- | -------------------------------------- |
| Työntekijät eivät ole motivoituneita ja eivät saavu paikalle | Pieni          | Suuri   | Pidetään työpaikalla kahvia ja pullaa. |
| Työntekijät sairastuu | Keskisuuri          | Suuri   | Sallitaan etätyö |
| Sovellus/Integraatio ei toimi | Suuri         | Suuri   | Pyydetään apua opettajilta ja muilta opiskelijoilta |
| Aikataulu jumittaa | Keskisuuri       | Suuri   | Pidetään kiinni scrum tavoitteista |
| Git ongelmia | Keskisuuri    | Suuri   | Selkeä kommunikointi |
| Tiimiläisten välinen kiista | Pieni    | Suuri   | Selkeä kommunikointi, pidetään taukoja, ei stressata liikaa |
